# Курсовой проект: Анализ облачной инфраструктуры

## Контрольная точка 1 (КТ1): Пять тестовых значений — формулы и базовый контроль

### Вариант 11

- **Компоненты:** `IOP`, `SRV`, `RAM`
- **Порядок записи во входных данных:** формат `значение время компонент` (разделитель — пробел). В текущей реализации ввод упрощён до последовательного ввода значений `IOP SRV RAM` для каждого отсчёта.
- **Тип последовательности (1):** записи идут по времени; на каждом отсчёте присутствуют все три компонента.
- **Телеметрия за пять отсчётов:**

| Отсчёт (t) | IOP  | SRV  | RAM  |
| :---: | :---: | :---: | :---: |
| 1 | 43.7 | 53.8 | 32.0 |
| 2 | 44.2 | 57.2 | 31.3 |
| 3 | 44.7 | 55.2 | 30.6 |
| 4 | 50.6 | 53.2 | 35.2 |
| 5 | 51.1 | 51.2 | 34.5 |

- **Производный показатель Q:** Относительное изменение  
  `Q[i] = 100 * (X[i] − X[i−k]) / X[i−k]`  
  Параметры: `k = 2`, `L = 2.0`, `D = 25`.
- **Правило состояния компонента (Превышение порога):**  
  Если `Q > L`, фиксируется состояние **«РОСТ»**.  
  Если `Q < -L`, фиксируется состояние **«СНИЖЕНИЕ»**.  
  В противном случае — **«НОРМА»**.
- **Правило инцидента (Противоположные тенденции):**  
  Инцидент возникает, если один компонент имеет состояние «РОСТ», а другой одновременно — «СНИЖЕНИЕ».

## 1. Алгоритм и блок-схема

### Описание алгоритма

1. Инициализировать параметры: `k = 2`, `L = 2.0`, лимит на 5 отсчетов. Переменные для хранения значений телеметрии обнуляются.
2. Последовательно считывать измерения телеметрии для каждого отсчета (`IOP`, `SRV`, `RAM`). 
3. На отсчетах 1 и 2 показания сохраняются в переменные окна (`iop1`, `srv1`, `ram1` и `iop2`, `srv2`, `ram2`). Так как данных предыстории на `k=2` шага назад еще нет, выводится состояние «НОРМА», инцидентов нет.
4. Начиная с отсчета 3:
   - Вычислить показатель `Q` для каждого компонента, сравнивая текущие значения со значениями из окна 2 шага назад (например, для `t=3` берутся данные за `t=1`).
   - Оценить состояние узлов через функцию `get_state()`: при `Q > L` статус «РОСТ», при `Q < -L` статус «СНИЖЕНИЕ», иначе «НОРМА».
   - Проверить наличие инцидента: если среди компонентов есть хотя бы один «РОСТ» и хотя бы один «СНИЖЕНИЕ», фиксируется инцидент.
   - Вывести данные и результат по текущему отсчету.

### Исходные данные телеметрии (упорядочены по отсчётам)

| :---: | :---: | :---: | :---: |
| 1 | 43.7 | 53.8 | 32.0 |
| 2 | 44.2 | 57.2 | 31.3 |
| 3 | 44.7 | 55.2 | 30.6 |
| 4 | 50.6 | 53.2 | 35.2 |
| 5 | 51.1 | 51.2 | 34.5 |

### Ручной расчёт производного показателя Q (k=2)

- **Отсчёт t=3 (пара с t=1):**
  - IOP: `Q[3] = 100 * (44.7 - 43.7) / 43.7 ≈ +2.29%`
  - SRV: `Q[3] = 100 * (55.2 - 53.8) / 53.8 ≈ +2.60%`
  - RAM: `Q[3] = 100 * (30.6 - 32.0) / 32.0 ≈ -4.38%`
- **Отсчёт t=4 (пара с t=2):**
  - IOP: `Q[4] = 100 * (50.6 - 44.2) / 44.2 ≈ +14.48%`
  - SRV: `Q[4] = 100 * (53.2 - 57.2) / 57.2 ≈ -6.99%`
  - RAM: `Q[4] = 100 * (35.2 - 31.3) / 31.3 ≈ +12.46%`
- **Отсчёт t=5 (пара с t=3):**
  - IOP: `Q[5] = 100 * (51.1 - 44.7) / 44.7 ≈ +14.32%`
  - SRV: `Q[5] = 100 * (51.2 - 55.2) / 55.2 ≈ -7.25%`
  - RAM: `Q[5] = 100 * (34.5 - 30.6) / 30.6 ≈ +12.75%`

## 3. Реализация программы

Исходный код программы: `Main.c`

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

// 1 - РОСТ, -1 - СНИЖЕНИЕ, 0 - НОРМА
int get_state(float q, float L) {
    if (q > L) return 1;
    if (q < -L) return -1;
    return 0;
}

const char* state_str(int state) {
    if (state == 1) return "РОСТ";
    if (state == -1) return "СНИЖЕНИЕ";
    return "НОРМА";
}

int process(int time, float prev_iop, float prev_srv, float prev_ram,
            float curr_iop, float curr_srv, float curr_ram) {
    float q_iop = (prev_iop != 0) ? 100.0f * (curr_iop - prev_iop) / prev_iop : 0.0f;
    float q_srv = (prev_srv != 0) ? 100.0f * (curr_srv - prev_srv) / prev_srv : 0.0f;
    float q_ram = (prev_ram != 0) ? 100.0f * (curr_ram - prev_ram) / prev_ram : 0.0f;
    
    int s_iop = get_state(q_iop, 2.0f);
    int s_srv = get_state(q_srv, 2.0f);
    int s_ram = get_state(q_ram, 2.0f);
    
    printf("%d\t%.2f%% (%s)\t%.2f%% (%s)\t%.2f%% (%s)\n",
           time, q_iop, state_str(s_iop), q_srv, state_str(s_srv), q_ram, state_str(s_ram));
           
    int has_rise = (s_iop == 1 || s_srv == 1 || s_ram == 1);
    int has_fall = (s_iop == -1 || s_srv == -1 || s_ram == -1);

    return (has_rise && has_fall) ? 1 : 0;
}

int main() {
    setlocale(LC_CTYPE, "RUS");
    float iop1, srv1, ram1;
    float iop2, srv2, ram2;
    float iop3, srv3, ram3;
    float iop4, srv4, ram4;
    float iop5, srv5, ram5;
    
    printf("Введите данные для 5 отсчетов (в каждой строке: IOP SRV RAM через пробел):\n");
    printf("Отсчет 1: ");
    scanf("%f %f %f", &iop1, &srv1, &ram1);
    printf("Отсчет 2: "); 
    scanf("%f %f %f", &iop2, &srv2, &ram2);
    printf("Отсчет 3: "); 
    scanf("%f %f %f", &iop3, &srv3, &ram3);
    printf("Отсчет 4: "); 
    scanf("%f %f %f", &iop4, &srv4, &ram4);
    printf("Отсчет 5: "); 
    scanf("%f %f %f", &iop5, &srv5, &ram5);

    printf("\nИсходные данные (5 отсчётов):\nВремя\tIOP\tSRV\tRAM\n");
    printf("1\t%.1f\t%.1f\t%.1f\n", iop1, srv1, ram1);
    printf("2\t%.1f\t%.1f\t%.1f\n", iop2, srv2, ram2);
    printf("3\t%.1f\t%.1f\t%.1f\n", iop3, srv3, ram3);
    printf("4\t%.1f\t%.1f\t%.1f\n", iop4, srv4, ram4);
    printf("5\t%.1f\t%.1f\t%.1f\n\n", iop5, srv5, ram5);

    printf("Показатель Q (относительное изменение, %%) и состояния (L=2.0):\nВремя\tIOP\t\tSRV\t\tRAM\n");

    int inc3 = process(3, iop1, srv1, ram1, iop3, srv3, ram3);
    int inc4 = process(4, iop2, srv2, ram2, iop4, srv4, ram4);
    int inc5 = process(5, iop3, srv3, ram3, iop5, srv5, ram5);

    printf("\nИнциденты (противоположные тенденции):\n");
    if (inc3) printf("Время 3: инцидент\n");
    if (inc4) printf("Время 4: инцидент\n");
    if (inc5) printf("Время 5: инцидент\n");
    if (!inc3 && !inc4 && !inc5) printf("Инцидентов не обнаружено.\n");

    return 0;
}
```
